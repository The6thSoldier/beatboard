The CS Behind It

Concept 01

Event Listeners

Every time you click a cell, JavaScript "listens" for that click and toggles the cell on or off. That's an event listener — the same idea that powers every button on the internet.

Concept 02

Loops

The beat repeats because of a loop. Every 8 steps, the playhead goes back to step 1 and starts over — just like a for-loop in code that keeps running until you tell it to stop.

Concept 03

Web Audio API

Browsers can generate sound using math. The Web Audio API lets JavaScript create oscillators — basically vibrating waves at specific frequencies — to make drum sounds without any audio files.

Concept 04

Data & Storage

When you submit a beat, the grid pattern (a 2D array of true/false values) is sent to an AI backend that stores it. The community wall fetches and displays everyone's stored beats.
